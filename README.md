# exercicios-algoritmos-e-programacao
# 🐍 Algoritmos e Programação com Python

## 📌 Sobre este repositório

Este repositório foi criado como um material de estudo e aprendizado de **Algoritmos e Programação utilizando Python**, durante o curso de Análise e Desenvolvimento de Sistemas (ADS).

O objetivo é construir uma base sólida em programação, partindo dos conceitos fundamentais e avançando gradualmente para conteúdos mais complexos.

Mais do que armazenar códigos e exercícios, este espaço será utilizado como um guia de estudos, reunindo explicações teóricas, exemplos práticos, exercícios resolvidos e desafios para desenvolver o raciocínio lógico e a capacidade de resolver problemas.

## 🎯 Objetivos de aprendizagem

- Compreender a lógica de programação desde os fundamentos.
- Desenvolver o raciocínio lógico e computacional.
- Aprender a interpretar e resolver problemas.
- Entender como os algoritmos funcionam antes de escrever o código.
- Dominar os fundamentos da linguagem Python.
- Praticar por meio de exercícios de diferentes níveis.
- Desenvolver autonomia para criar programas e solucionar problemas.

## 📚 Trilha de aprendizagem

Os conteúdos serão organizados em uma sequência progressiva, respeitando a evolução do aprendizado.

### Módulo 01 — Fundamentos da programação
- O que é programação?
- O que são algoritmos?
- Lógica de programação e resolução de problemas.
- Pseudocódigo e fluxogramas.
- Introdução ao Python.
- Instalação e configuração do ambiente.

### Módulo 02 — Variáveis e tipos de dados
- O que são variáveis?
- Regras para nomeação de variáveis.
- Tipos de dados: `int`, `float`, `str` e `bool`.
- Declaração e atribuição de valores.
- Entrada de dados com `input()`.
- Saída de dados com `print()`.
- Conversão de tipos.

### Módulo 03 — Operadores
- Operadores aritméticos.
- Operadores relacionais.
- Operadores lógicos.
- Operadores de atribuição.
- Precedência de operadores.

### Módulo 04 — Estruturas condicionais
- Tomada de decisões.
- Estrutura `if`.
- Estrutura `else`.
- Estrutura `elif`.
- Condições aninhadas.
- Operadores lógicos aplicados às condições.

### Módulo 05 — Estruturas de repetição
- Conceito de laços de repetição.
- Estrutura `while`.
- Estrutura `for`.
- Função `range()`.
- Controle de repetição com `break` e `continue`.
- Laços aninhados.

### Módulo 06 — Estruturas de dados
- Listas.
- Tuplas.
- Dicionários.
- Conjuntos (`set`).
- Percorrendo e manipulando coleções.

### Módulo 07 — Funções
- O que são funções?
- Criação e chamada de funções.
- Parâmetros e argumentos.
- Retorno de valores com `return`.
- Escopo de variáveis.
- Modularização do código.

### Módulo 08 — Fundamentos complementares
- Manipulação de strings.
- Tratamento de erros e exceções.
- Leitura e escrita de arquivos.
- Depuração de código.
- Boas práticas de programação.

### Módulo 09 — Prática e resolução de problemas
- Exercícios de lógica de programação.
- Problemas matemáticos.
- Desafios com condicionais e repetições.
- Exercícios envolvendo listas e funções.
- Pequenos projetos para consolidar o aprendizado.

## 📝 Metodologia de estudo

Cada conteúdo será desenvolvido seguindo uma estrutura de aprendizagem:

1. **Teoria:** explicação dos conceitos e fundamentos.
2. **Exemplos:** códigos comentados e explicados passo a passo.
3. **Prática guiada:** exercícios com orientação.
4. **Exercícios individuais:** atividades para testar o conhecimento.
5. **Desafios:** problemas para desenvolver autonomia.
6. **Revisão:** retomada dos conceitos e correção de dificuldades.
